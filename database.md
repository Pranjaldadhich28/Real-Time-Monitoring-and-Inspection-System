# database.md — DoSJE Monitoring App Schema

PostgreSQL via Django ORM. Four apps: `accounts`, `projects`, `inspections`, `reports`.

## accounts

### Division
| Field | Type | Notes |
|---|---|---|
| id | AutoField | PK |
| name | CharField | e.g. "Ranchi Division" |

### User (extends AbstractUser)
| Field | Type | Notes |
|---|---|---|
| role | CharField (choices) | `super_admin`, `official`, `inspector`, `ngo` |
| division | FK → Division | null=True (super_admin has none / sees all) |
| ngo | FK → NGO | null=True, only set when role="ngo" |
| phone | CharField | for notifications |

### NGO
| Field | Type | Notes |
|---|---|---|
| id | AutoField | PK |
| name | CharField | |
| registration_number | CharField | |
| division | FK → Division | |

## Access rules (enforce at queryset level, not just view level)
- `super_admin`: no filter, sees everything
- `official`: filter by `division` on all above models
- `inspector`: filter to only their own `InspectionAssignment` rows and related reports
- `ngo`: filter by `ngo` FK on `Project`/`Beneficiary`/`PurposeItem`, read-only
